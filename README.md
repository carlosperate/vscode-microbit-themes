Six VS Code colour themes inspired by the BBC micro:bit.
**Pixel**, **Spark**, and **Halo**, each in light and dark versions.

![screenshot with all themes](docs/screenshots/preview-small.png)

## Themes

| Theme           | Modes        | Colour pair   |
| --------------- | ------------ | ------------- |
| micro:bit Pixel | Light / Dark | Green + Blue  |
| micro:bit Spark | Light / Dark | Red + Orange  |
| micro:bit Halo  | Light / Dark | Purple + Teal |

## Install

**From the Marketplace**

1. Open the Extensions view (`⇧⌘X` / `Ctrl+Shift+X`).
2. Search for `micro:bit Themes`.
3. Click **Install**.

## Activate a theme

1. Press `F1` (or `⇧⌘P` / `Ctrl+Shift+P`).
2. Run **Preferences: Color Theme**.
3. Pick any **micro:bit …** entry.
