# Theme showcase workspace

Sample files that put as many theme colours on screen as possible. Open it
with `npm run desktop` (desktop VS Code, with Theme Builder for the workbench
mockups) or `npm run serve` (VS Code Web).

## What is where

- `main.py`, `blink.cpp`: MicroPython and CODAL C++, as the micro:bit IDE runs them.
- `app.ts`: TypeScript with a deliberate type error, for squiggles and Problems.
- `conflict.py`: merge conflict markers, decorated by the built-in merge conflict support.
- `notebook.ipynb`: a notebook with stored outputs, no kernel needed.
- `theme-tester/`: Microsoft's theme preview samples, the files `vscode.dev/theme/<id>` opens.
- *Inline* `code`, [a link](https://microbit.org) and a quote:

> Nothing here is a real program.
